## 本轮修复

1. 采购入库资产名称、供应商、SN、位置和履历重复 HTML 转义。改为保存原始值，只在渲染时转义。
2. 批次入库只有成功提示。新增批次编号、数量、库位及来源记录，采购详情可查；重复确认拦截。采购批次与独立领用样例库存明确区分。
3. 采购价格 0.001 等数值四舍五入可能变零。增加最低金额和两位小数校验。
4. 旧审批按钮可推进新步骤。按钮绑定步骤版本，执行时核对阶段，拦截重复推进。
5. 新建 VM 未同步主机清单。创建后登记主机身份、负责人、MAC/IP，并支持停止状态同步与远程拦截。
6. 主机和 VM 的部分用户输入输出统一转义。
7. 表单按 Enter 可能刷新或不提交。统一阻止默认导航，校验后触发当前弹窗主动作，textarea 保留换行。
8. 增加 hashchange，手工修改地址和历史返回正确更新页面。
9. 手机菜单支持 Esc 收起并恢复焦点。
10. 监控存储恢复前校验 null 等损坏行，新增监控限制与 200 项恢复上限保持一致。
11. 归还验收结果校验；主题存储失败给出准确提示。
12. 领用成功文案原来声称修改全局资产保管人，实际仅更新独立样例库存。改为准确说明申请交接责任，逐件全局分配仍待实现。

PVE IP 冲突、创建、主机登记、停止及远程拦截；受管 IP 只读、广播 MAC 拦截和合法绑定；流量详情；应用 URL 凭据拦截及登记待接入；告警确认和工单；自动化预检、审批、执行、回读与健康验证；新增监控和刷新保存。

回车提交、主题取消与刷新保存、标签关闭、手机 Esc、全部页面内容、按钮名称、溢出，以及实际下载资产 CSV、财务 CSV、RDP 配置。测试下载文件保存在浏览器下载目录。
