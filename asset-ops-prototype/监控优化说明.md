## 已实现

- 服务列表支持名称、目标、负责人、分组搜索以及状态筛选；选择服务后联动详情、心跳与曲线。
- 1 小时、24 小时、7 天使用同一份固定演示历史重新统计，曲线和统计值随范围变化。
- 可点击心跳格查看该段可用率和覆盖率；图表悬停显示最近采样及单位。
- 新增和编辑监控支持名称、类型、目标、间隔、超时、重试、响应提醒阈值、内容关键词、TCP 端口、应用/主机关联和状态页展示范围。
- 新增或更换探测目标不继承其他目标的历史；保持待采样。只改负责人等元信息保留历史。
- 暂停、恢复、维护设置和结束维护有独立状态；恢复后等待新采样，不能把旧成功记录当新心跳。
- 主机资源基于既有主机 ID 关联，显示 CPU、内存、磁盘、网络、I/O 历史及容器样例；关联应用、软件端口和远程入口可跳转。
- 离线和已停止主机的指标为未知，图表为空；远程入口禁用。
- 告警阈值、持续时间、恢复次数、证书提前提醒和通知渠道可配置；配置变更记录在当前浏览器。
- 状态页按选中服务生成仅含展示名称和状态的预览，不包含目标、IP、负责人或凭据；尚未发布公网。

## 指标规则

可用率 = 正常有效时长 / (正常有效时长 + 故障有效时长)。维护/暂停时段不计入分母，未知时段不被判为成功或故障。

覆盖率 = 已知正常/故障时长 / (所选窗口时长 - 维护/暂停时长)。一个服务可能在低覆盖率下显示 100% 有效可用率，因此两者一起展示。无有效样本显示空值而不是 100%。

时长按样本覆盖区间裁剪，并避免重复时间戳重算。p95 从成功响应的原始演示样本计算；曲线按展示时段聚合，p95 不是聚合点的简单平均。Push 心跳不适用响应时间。故障之后只有观测成功才产生恢复时间，未知不会冒充恢复。

每个心跳格代表一个时间段：出现失败优先标红，没有有效观测标灰。维护与暂停单独着色并配文字图例。

## 演示与真实功能边界

当前为静态前端，没有部署 Kuma/Beszel，没有安装 Agent，没有自动网络探测、后台定时任务或真实通知。历史由确定性演示数据生成，基准时间固定为 2026-10-23 14:30（北京时间）。

主机身份、软件端口和启停状态引用现有基础设施模块；性能曲线是 10/23 的独立演示数据，不代表旧模块 10/08 实测结果。S.M.A.R.T.、温度、GPU 未采集时保持未采集，不造数。

监控配置保存在 `qiyun.monitoring.v1`。数据留在浏览器，不跨用户、不跨设备同步；其中包含登记的目标地址，禁止保存密钥或敏感 URL 参数。浏览器存储不可用时提示内存模式。旧业务模块仍使用当前页临时状态。恢复初始配置保留一个仅当前页面可撤销的副本，刷新后该撤销副本消失。

告警确认和策略配置是本地交互。策略不会改写历史样例事件或发送消息；这些功能的正式执行与审计需要服务端。状态页虽然只输出安全字段，但仍位于管理原型中，不能直接将包含全部管理数据的 index.html 当公开状态服务部署。

## 真实引擎接入建议

平台保留资产、应用、人员、审批与工单的权威记录；Kuma 和 Beszel 分别作为可用性与资源监控引擎，由服务端适配器关联到稳定 service_id/resource_id。

1. **服务端适配器**：固定部署版本并核对认证、权限和接口能力。Kuma README 不等于稳定的通用管理 REST API 合约，不能按猜测端点实现；对 Socket.IO/版本相关能力增加契约测试。Beszel Hub 基于 PocketBase，需核对目标版本的集合、权限和采集模式后接入。
2. **观测归一化**：保存 source、source_id、observed_at、received_at、fresh_until、status、metric、unit、labels 和 schema_version，区分源不可达与被监控对象不可达。
3. **单一告警发送责任**：明确由原引擎发通知还是平台统一路由，避免双重告警。Webhook 先验签/验源、限流、按事件 ID 去重，最后关联工单。
4. **资源认领**：外部监控项和主机按源 ID 绑定现有资产/应用。目标 IP、名称和标签变化不能创建重复资产或覆盖采购/归属字段。
5. **控制分离**：监控 Agent 不自动取得 SSH、PVE 写入或远程桌面权限。容器采集所需 socket 权限单独评估，禁止为了监控默认开放不受保护的 Docker API。
6. **网站探测边界**：后端按授权网区和目标范围限制 DNS、重定向及目的端口，防止探测成为任意内网访问入口；TLS 校验保留。Push 令牌由后端生成并托管，前端原型不生成假令牌。
7. **公开状态页**：独立只读接口返回脱敏投影，与管理页和会话隔离；发布目标、范围和访问策略确定后再上线。
